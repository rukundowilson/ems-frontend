The frontend is implemented using Next.js + TypeScript and is responsible for:

Displaying user interfaces:

Homepage 

Event list & details

Booking forms

User and admin dashboards

Handling client-side routing

Validating form inputs before submission

Communicating with backend APIs

Integrating Firebase Authentication for secure login/registration

Displaying notifications and error messages

Managing application state (e.g., selected event, booked slots)
